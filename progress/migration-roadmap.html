Risks and open questions

  • Stacked unmerged PRs. Nothing from #3 or #5 reaches master until both land in order.
  • Web persistence unproven. expo-sqlite on web is alpha; contract tests run on sql.js only (ADR 0003). The uncommitted web.output: single change trades static routes for a working dev server and needs a host fallback.
  • No device pass recorded for the reader parity work; jest coverage only.
  • Licensing. Bundled KJV provenance is unverified; terms for Upstream's hosted server are unconfirmed, which is why Online features stay parked.
  • Overall estimate. Phases 1 to 3 roughly 80 percent; whole migration well under half, because phases 4 and 5 are large and unscoped. This is a judgment from the progress log, not a measurement.
